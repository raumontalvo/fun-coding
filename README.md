# Fun Coding Practice Tool

An interactive, accessible web app to teach coding step-by-step. Users assemble code by selecting syntax blocks, progressing through modules on variables, arrays, loops, conditionals, functions, objects, and a final challenge.

## Features
- Clean, responsive layout for desktop and mobile
- Step-by-step instructions and immediate feedback
- Progression through core coding concepts
- Hints and real-world examples for each concept
- Progress tracker and dashboard
- Practice mode to revisit concepts
- Accessibility: keyboard navigation, ARIA labels, high-contrast, flexible pacing

## Modules

The curriculum is organized into progressive modules, each focusing on a core programming concept. Every module includes interactive tasks, real-world examples, hints, and step-by-step explanations.

### 1. Variables
- **Goal:** Understand variables, assignment, and data types.
- **Topics:** Declaring variables, naming rules, assigning values, updating variables, string and number basics.
- **Activities:** Identify valid variable names, fix assignment errors, assemble simple variable statements.
- **Real-World Example:** Storing a user's score in a game.

### 2. Arrays
- **Goal:** Learn how to store and access lists of data.
- **Topics:** Creating arrays, indexing, updating elements, array length, iterating basics.
- **Activities:** Build arrays, access elements, fix off-by-one errors, assemble array operations.
- **Real-World Example:** Managing a list of high scores.

### 3. Loops
- **Goal:** Master repeating actions with loops.
- **Topics:** for-loops, while-loops, loop conditions, incrementing, breaking out of loops.
- **Activities:** Complete loop bodies, fix infinite loops, assemble counting and summing tasks.
- **Real-World Example:** Looping through player inventory.

## Usage
- Select a module from the sidebar or dashboard
- Read the prompt and assemble code using the tappable blocks
- Submit your answer for instant feedback
- Use the hint button if you get stuck
- Track your progress and revisit modules anytime

## Accessibility
- All interactive elements are keyboard-accessible
- ARIA labels and roles for screen readers
- High-contrast colors and resizable text
- No time limits; users control pacing
